# Style reference - voices

Register rulings are in `glossary.md` (Rulings, D8). One row per voice the script shows often.

| Character | Voice in English |
|---|---|
| Rai Ryuga | brash, rough, warm: contractions, "gonna", "ya", exclamations; never formal |
| Shishin | calm strategist, polite to Rai ("my lord" sparingly), plain clear sentences |
| Shimon | gentle, devoted, firm when needed |
| Ranran | kansai-ben: chirpy, casual ("ain't", "y'know"), teasing |
| Sho Shigen, Mokaku, old generals | gruff veterans, formal but blunt ("I shall", no "thou") |
| Rako | cold, proud, scheming; clipped, superior |
| Kyo Shisho | loyal, proud warrior of Ren; formal, devoted to his lord's conquest |
| Masamune | commanding heroine, direct, bold |
| Hiryu | loyal aide, urgent reports ("My lady!") |
| Gaira | tyrant emperor: arrogant, contemptuous ("Insolent!") |
| Roha | proud woman general, sharp, scornful |
| Battle-quote officers | short taunts and boasts; villains sneer, heroes rally |
| Advisors | address the player's lord by rank: "My lord", "Your Majesty", "Sire" as the JP (殿/お館様/陛下) |
